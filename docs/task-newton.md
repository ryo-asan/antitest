# タスク: 拡大Newton法による分岐図作成と適応的ステップサイズ制御

## 1. コンパイルおよび実行コマンドの指定
- コードのコンパイルおよびテスト実行を行う際は、必ず以下のコマンドを厳密に使用すること。
- 実行時の標準出力ログは `tee` コマンドを用いて `output_txtdata/execution_log.txt` に保存すること。

`g++ -I.. -DNDEBUG -DKV_FASTROUND -O3 onenorm.cpp -llapack -lblas -Wl,--no-as-needed -lmkl_intel_lp64 -lmkl_intel_thread -lmkl_core -liomp5 -lpthread -lm -ldl -lmpfr -fopenmp && ./a.out | tee output_txtdata/execution_log.txt`

## 2. 目的と前提
- 対象ファイル: `onenorm.cpp`
- パラメータ $N$ を変化させながらNewton法を連続実行し、解の分岐を追跡する。
- `kv` や `vcp` ライブラリの型や行列の結合ロジックは一切壊さないこと。
- **【重要】元のコードに存在した `std::cout` による各種変数の出力（ヤコビ行列 `Y`、残差 `F`、修正量 `syuusei_extend`、ノルム値など）は、計算過程の確認に必須であるため、絶対に削除・コメントアウトせずにすべて残すこと。**

## 3. ループ構造と初期値の引き継ぎ（コンティニュエーション）
- 既存の1回だけのNewton法を、パラメータ $N$ に関するループ（例: while文やfor文）で囲む。
- **【重要: 1回目の初期化】** ループに入る前に1度だけ、`bunki/value/` ディレクトリ内にあるファイルから最初の `uh`, `vh`, `wh` を `vcp::load` で読み込み、`epsilon` の初期値を `0.025` に設定すること。
- **【重要: 2回目以降の引き継ぎ】** ニュートン法によって解と `epsilon` は毎ステップ更新されるため、ループ内では `uh.ones(...)` や `epsilon` の初期化を絶対に行わない。常に一つ前のステップで収束した解と更新された `epsilon` を、次のループの初期値としてそのまま使用し続けること。

## 4. 適応的ステップサイズ（バックトラック）
- 不安定解から別の解への吸い込みを防ぐため、各ステップの前に状態（uh, epsilon, N）をバックアップ変数に退避させる。
- 収束後、前回の解からの変化量（`max(abs(uh - uh_old))` や epsilon の変化）が閾値を超えた場合は「別解へジャンプした」と判定する。
- ジャンプを検知した場合は、退避させたバックアップから状態を巻き戻し、Nの刻み幅 $\Delta N$ を半分にして再試行すること。

## 5. データの保存（I/O）と出力先の振り分け
- 正常に収束し、ジャンプ判定もクリアした場合のみ、以下のルールに従ってデータを2つのディレクトリに分けて保存すること。
- **【分岐図用のテキストデータ】出力先:** `output_txtdata`
  - 各ステップの $N$, `epsilon`, $H^1_0$ ノルムなどの連続する計算結果は、`output_txtdata/bifurcation_data.csv` （またはテキストファイル）に追記して保存すること。
- **【近似解の行列データ】出力先:** `value`
  - `vcp::save` を使い、`std::stringstream` を用いて以下のようなファイル名を動的に生成し保存すること。
    - `value/eps_[epsilonの値]_H10_[H10の値]_uh`
    - `value/eps_[epsilonの値]_H10_[H10の値]_vh`
    - `value/eps_[epsilonの値]_H10_[H10の値]_wh`
