# VCPライブラリを用いた非線形方程式の分岐解析・解の追跡プログラム

本プログラムは、精度保証付き数値計算ライブラリである **VCP Library** および **KV Library** を利用し、ルジャンドル多項式を用いたガラーキン法によって非線形微分方程式の近似解を求めるC++プログラムです。

特に、パラメータ（ノルム制約 $N$ ）を少しずつ変化させながらニュートン法を反復し、未知のパラメータ $\epsilon$ と解関数 $u_h$ を同時に探索する**連続法（解の枝の追跡）**を実装しています。

## 1. 主要なライブラリとデータ型
プログラムの冒頭で定義されている型は、精度と計算手法を決定する重要な役割を担っています。

* **`AppData` (kv::dd)**: Double-Double演算（倍精度浮動小数点数の約2倍の精度、約32桁）を使用してメインの計算を行います。
* **`vcp::matrix`**: VCPライブラリが提供する行列クラス。
* **`vcp::Legendre_Bases_Generator`**: ルジャンドル多項式を基底関数 $\phi$ として生成し、内積などの行列を自動構築するジェネレータです。

## 2. 物理パラメータと初期設定
方程式の挙動を決定する各種パラメータが定義されています。

| 変数名 | 初期値 | 説明 |
| :--- | :--- | :--- |
| `Order_legendre` | 40 | ルジャンドル多項式の最大次数（空間解像度） |
| `p` | 3 | 非線形項の最大次数（例: $u^3$ を扱うため） |
| `D, alpha, beta, gamma` | (各種) | 支配方程式の係数パラメータ |
| `N` | 1.289 | 追跡パラメータ（解のノルム制約などに相当） |
| `epsilon` | 0.025 | 探索対象となる分岐パラメータ |

あらかじめ外部ファイル（`value/test2_uh_eps_...` など）から、初期推測値となる $u_h, v_h, w_h$ の係数ベクトルを読み込んでいます。

## 3. 数学的定式化と拡張ニュートン法
プログラムの中核は、関数 $u$ とパラメータ $\epsilon$ を同時に解くための**拡張系（Extended System）に対するニュートン法**です。

剛性行列 $DL$ ( $\nabla \phi_i \cdot \nabla \phi_j$ ) と 質量行列 $L$ ( $\phi_i \cdot \phi_j$ ) を生成した後、残差ベクトル $F$ とヤコビ行列 $Y$ を構築して更新量 `syuusei_extend` を求めます。

ブロック行列として以下のような構成をとっています。

$$
Y \begin{pmatrix} \Delta u \\ \Delta \epsilon \end{pmatrix} = \begin{pmatrix} F_u \\ F_S \end{pmatrix}
$$

* **$F_u$ (方程式の残差)**:
    非線形項（$\alpha u - \beta u^2 + \gamma u^3$ など）や $\epsilon$ に依存する項を含む、方程式の弱形式の残差。
* **$F_S$ (制約条件の残差)**:
    プログラム中では $F_S = \sqrt{u_h^T DL u_h} - N$ として定義されており、$u$ の $H^1_0$ セミノルムが $N$ に一致するという制約を課しています。
* **$Y$ (ヤコビ行列)**:
    偏微分成分によって構成されます。
    * $DF_u$ : 残差の方程式成分の $u$ による微分
    * $F_{epsilon}$ : 残差の方程式成分の $\epsilon$ による微分
    * $G_u$ : 制約条件の $u$ による微分
    * $G_{epsilon}$ : 制約条件の $\epsilon$ による微分（ここではゼロ）

## 4. プログラムの実行フロー（ステップ進行）
解の枝（Solution Branch）を追跡するために、以下のループ処理を行います。

1.  **ステップ進行**: 目標パラメータ $N$ を $dN = 0.002$ ずつ増加させます。
2.  **ニュートン反復**:
    * ヤコビ行列 $Y$ と 残差 $F$ を計算します。
    * 線形方程式 `lss(Y, F)` を解き、修正量 `syuusei_extend` を取得します。
    * $u_h$ と $\epsilon$ を更新します。
    * 修正量の最大値（無限大ノルム）が $2^{-30}$ を下回れば収束とみなします。
3.  **適応的ステップ制御（Adaptive Stepping）**:
    * **収束した場合**: 更新幅が大きすぎないかチェック（$\Delta u > 0.3$ または $\Delta \epsilon > 0.05$ であればジャンプしたと判定）。問題なければデータをCSV (`bifurcation_data.csv`) とファイルに保存し、次のステップへ。
    * **収束失敗・ジャンプした場合**: 状態をバックアップに戻し、ステップ幅 $dN$ を半分（$dN / 2.0$）にして再計算します（適応的ステップサイズ制御）。
4.  **事後評価**:
    計算終了後、区間演算（`kv::interval`）を用いて近似解 $u_h$ の厳密な大域的最小値・最大値を計算し、出力します。

## 5. 出力ファイル
* **`value/eps_*_H10_*_uh`**: 各ステップで得られた近似解 $u_h$ のベクトルデータ。
* **`output_txtdata/bifurcation_data.csv`**: 分岐図を描画するためのデータ列（ $N$, $\epsilon$, $\|u_h\|_{H^1_0}$ ）。
