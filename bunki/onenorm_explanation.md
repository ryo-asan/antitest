# onenorm.cpp プログラム詳細解説

本ドキュメントは、パラメータ $N$（$H^1_0$ ノルム）を変化させながらニュートン法を連続実行し、解の分岐図を追跡・作成するために実装・修正された `onenorm.cpp` の詳細な動作と構造を解説するものです。

---

## 1. プログラムの概要と目的

このプログラムは、VCP (Verified Computation) ライブラリを用いて非線形偏微分方程式の近似解（ガラーキン近似解など）を精度保証付きで計算するためのベースとなるニュートン法を実行します。
特に、解のノルム $N$ を制御パラメータとする「コンティニュエーション（連続・ホモトピー法）」を1つのプログラム内で完結して実行する仕組みを持っています。

主な目的は以下の通りです：
1. 指定された初期解から出発し、パラメータ $N$ を少しずつ変化させる。
2. 変化した $N$ に対応する新しい解（および未定乗数としての `epsilon`）をニュートン法で計算する。
3. 計算された一連の解の遷移を分岐図データとして記録し、各ステップの解の行列データを保存する。
4. 途中で別の解へのジャンプや発散の兆候を検知した場合、自動で刻み幅（ステップサイズ）を調整して再計算する（適応的ステップサイズ制御）。

---

## 2. 全体構造と処理フロー

プログラムは、大きく分けて以下のフェーズで構成されています。

### フェーズ 1: 初期化と事前準備（ループ外）
- **基底の準備**: ルジャンドル多項式を用いた基底関数列の生成（`Approximate_Generator`）と、ラプラシアンや質量行列に相当する `DL`, `L` 行列の作成。
- **初期解のロード**:
  プログラム起動時に一度だけ、`bunki/value/` フォルダ内にある既存の初期解データ（`uh`, `vh`, `wh`）を `vcp::load` で読み込みます。
- **初期 $N$ の算出**:
  読み込んだ初期解 `uh` から、その初期状態での正確な $H^1_0$ ノルムを逆算して $N$ に設定します。
  ```cpp
  N = (double)sqrt(transpose(uh)*DL*uh)(0);
  ```
  これにより、ニュートン法の1歩目での残差が最小限に抑えられ、発散を防いでいます。

### フェーズ 2: 連続実行ループ（コンティニュエーション）
```cpp
for (int step = 1; step <= max_steps; step++) { ... }
```
プログラムは1回の起動で、このループを通じて指定回数（`max_steps`）だけパラメータ $N$ を進めます。

1. **状態のバックアップ**
   各ステップの最初に、現在の解 `uh`、`epsilon`、および `N` を退避（バックアップ）します。
2. **パラメータの更新**
   `N += dN;` により、目標とする $N$ を刻み幅ぶんだけ進めます。

### フェーズ 3: ニュートン法による非線形方程式の求解（内側ループ）
```cpp
while(1) { ... }
```
前回のステップで収束した解をそのまま「初期推測値」として利用します（ループ内で `uh` をゼロクリアしたり `ones` で再初期化しないことが重要です）。

- **ヤコビ行列 `Y` と残差ベクトル `F` の構築**:
  方程式の微分系から計算されるブロック行列 `Y` と、残差 `F` を構築します。プログラム内では計算過程確認のため、これらを必ず `std::cout` で出力しています。
- **線形方程式の求解と解の更新**:
  `syuusei_extend = lss(Y, F);` で修正量を求め、`uh` および `epsilon` を同時に更新します。
- **収束判定**:
  修正量の最大値が閾値（`pow(2.0, -30)`）を下回れば収束とみなしてループを抜けます。

### フェーズ 4: 適応的ステップサイズとジャンプ検知
ニュートン法が収束しなかった場合、または「解の変化量 (`diff_u`) や `epsilon` の変化量 (`diff_eps`) が大きすぎる」場合（別分岐へのジャンプ）、以下のバックトラック処理が行われます。
- 退避させておいたバックアップから状態（`uh`, `epsilon`, `N`）を復元する。
- 刻み幅 `dN` を半分（`dN /= 2.0;`）にする。
- 現在のステップをやり直す（`step--;`）。

### フェーズ 5: データの保存
ジャンプ判定もクリアして正常に収束した場合のみ、後続の研究やプロットに使えるデータを保存します。
- **分岐図用テキスト**:
  `output_txtdata/bifurcation_data.csv` に対して、$N$, `epsilon`, 収束した解の $H^1_0$ ノルムを追記保存します。
- **行列データ**:
  `value/eps_[epsilon]_H10_[H10]_uh` のように、現在の `epsilon` とノルムの値を動的に埋め込んだユニークなファイル名で、`uh`, `vh`, `wh` の状態を保存します。

## 3. コード設計上の重要なポイント

1. **初期値と残差の整合性 (Zero-residual starting)**
   単に $N$ を固定の数値から始めるのではなく、読み込んだ `uh` の値から $N$ を逆算している点が非常に重要です。これにより $N$ の急激なギャップによるニュートン法の崩壊を防止しています。
2. **完全な自己完結プログラム**
   外部のシェルスクリプトに依存せず、C++プログラムのメモリ空間内で直接データを引き継ぎながら計算を進めるため、非常に高速に分岐を追跡できます。ファイルの読み込みオーバーヘッドも最初の1回だけです。
3. **計算過程の透明性**
   ヤコビ行列 `Y` や 残差 `F` などを毎反復で標準出力に出すことで、どこで発散したか、または特異行列に陥ったかをシェルから容易にデバッグできるように設計されています。

## 4. コンパイルおよび実行方法

計算過程のログは画面に出力しつつファイルにも保存するため、`tee` コマンドを使用します。

```bash
g++ -I.. -DNDEBUG -DKV_FASTROUND -O3 onenorm.cpp -llapack -lblas -Wl,--no-as-needed -lmkl_intel_lp64 -lmkl_intel_thread -lmkl_core -liomp5 -lpthread -lm -ldl -lmpfr -fopenmp && ./a.out | tee output_txtdata/execution_log.txt
```
